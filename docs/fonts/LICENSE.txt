======================================

landing pages (index.html / index-en.html). All fonts listed below are
distributed under the SIL Open Font License, Version 1.1.

  https://openfontlicense.org

   SIL Open Font License 1.1 — https://openfontlicense.org
   Files: source-serif-4-latin.woff2, source-serif-4-italic-latin.woff2

2. IBM Plex Mono
   Copyright © 2017 IBM Corp., with Reserved Font Name 'Plex'.
   Designed by Mike Abbink & Bold Monday.
   SIL Open Font License 1.1 — https://openfontlicense.org
   Files: ibm-plex-mono-400-latin.woff2, ibm-plex-mono-500-latin.woff2

3. Noto Serif SC (subset, served as "MK Serif SC")
   Copyright 2012-2019 Google Inc., with Reserved Font Name 'Noto'.
   SIL Open Font License 1.1 — https://openfontlicense.org
   File: mk-serif-sc-600.woff2
   Note: a character subset (text= subsetting via the Google Fonts
   css2 API) containing only the glyphs used by the Chinese landing
   page headings. Regenerated by scripts/fonts/build-cjk-subset.mjs.
