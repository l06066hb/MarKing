浏览功能

v1.6.2 · Windows / macOS / Linux · 无需注册

纯文本，不锁定

全平台

02表达

公式、图表与白板，写进同一篇文档。

技术写作需要的不只是文字。可视化公式、Mermaid 图表、手绘白板与表格编辑都内置在编辑器里，不必在工具之间来回切换。

公式

MathLive 可视化编辑，配合虚拟键盘输入；\label 与 \eqref 自动编号，点击即可跳转。

图表

完整支持 Mermaid 11，新增架构图、时间线、桑基图、C4 等 8 种图表。

表格

像电子表格一样编辑 Markdown 表格，单元格可换行，保存时保留原有格式。

白板

内嵌 Excalidraw 手绘白板，流程与架构草图随手画进文档。

同样内置 — Callout 提示框 · 脚注 · 任务列表 · 代码高亮主题 · 上下标 · 中西文自动空格 · HTML 文件

03连接

笔记不再是孤岛。

用 [[双链]] 连接想法，反向链接与知识图谱让脉络一目了然。网页、Word、PDF，也能一步转成 Markdown 笔记。

双向链接

输入 [[ 即可链接任意笔记，反向链接自动汇总。

知识图谱

万级节点依旧流畅，支持全屏沉浸与图片导出。

导入一切

CtrlShiftV

网页 URL、Word、EPUB、PDF 一键转为 Markdown；富文本粘贴自动转换。

任务系统

汇总全库待办，支持优先级与截止日期，勾选即回写原文。

模板与日记

CtrlAltD

6 个内置模板，支持日期等变量；一键打开今日日记。

04AI

AI 只是助手，
执笔的永远是你。

接入你信任的模型，在编辑器里完成润色、翻译、排版与成文。每一处修改都以对比呈现，由你逐条决定去留。

AI 排版

CtrlAltF

一键整理结构与格式，修改逐处以 Diff 呈现，可逐条接受或拒绝。

行内 AI

选中文字即可改写、总结、翻译或扩展，流式输出，随时可停。

写作流

从多篇笔记合成文章或提炼大纲，多轮精修，草稿存回笔记库。

你的模型，你的密钥

内置 18+ 家服务商，兼容自定义 API；密钥加密存于本地，请求直达你选择的服务商。标记 #private 的笔记，AI 排版与写作流会自动跳过。

MCP Server

让 AI 客户端，读懂你的笔记库。

Claude Desktop、Cursor、Cline 等 MCP 客户端可通过本地 stdio 检索与读写笔记、管理任务。默认关闭；写入需单独授权，每次写操作都会记入审计日志。
